# ADR-003: Statistical predictor first; no LLM on the request path

## Context

Microsecond predictions, zero token cost, explainable.

## Decision

Statistical predictor first; no LLM on the request path.

## Consequences

Trade-off accepted: Misses intent that only language understanding would catch.

## Status

Accepted

Source: architecture.md section 13. Change this decision only with a new ADR.
