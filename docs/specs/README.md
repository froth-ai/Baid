# Specs

The specification is written in the team doc and exported here as Markdown, one file per tab
(team-plan.md 0.1 step 2). Prompts say "X tab section N"; that means `docs/specs/X.md`.

| File | Team doc tab |
| --- | --- |
| `accelerator-plan.md` | Accelerator plan |
| `srs.md` | SRS |
| `architecture.md` | Architecture and design |
| `code-architecture.md` | Code architecture |
| `research.md` | Research and reading |
| `team-plan.md` | Team plan and prompts |

Re-export a file whenever its tab changes, and commit it in a `docs:` pull request.
